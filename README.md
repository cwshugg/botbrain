# Botbrain

My personal collection of knowledge to guide AI agents when I work.

## Using the Knowledge

Requires Python 3.10+; no dependencies.

```bash
# Run unit tests
python3 -B -m unittest discover -s tests -v

# Install knowledge to your local `~/.copilot/`
python3 install.py

# Install somewhere else
python3 install.py --destination "./path/to/your/custom/location"
```
